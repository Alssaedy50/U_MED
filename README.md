# UMED — منصة التعليم الطبي (اليمن أولاً)
### Yemen-First Medical Education Platform

UMED هي منصة تعليم طبي عربية، خفيفة وسريعة، مصممة خصيصاً لطلاب كليات الطب والجامعات في اليمن. تهدف إلى توفير وصول فوري للمناهج الدراسية، المواد العلمية منخفضة استهلاك البيانات، ونظام اختبارات ومسابقات أكاديمية آمن وموثوق.

---

## 🏛️ الميزات الجوهرية (الإصدار الأول)

1. **هيكل أكاديمي ديناميكي بدون تعديل برمجيات**:
   - دعم الجامعات اليمنية (الجامعة التوضيحية الأولى: جامعة دار السلام الدولية للعلوم والتكنولوجيا - كلية الطب البشري).
   - هيكل المستويات السبعة النظامية مع مرحلة سنة الامتياز ككيان سريري مستقل.
   - نظام البلوكات ونظام الفصول والمقررات مع دعم الأقسام النظرية والعملية.

2. **تجربة مستخدم عربية موجهة للهواتف الذكية**:
   - واجهة كاملة بنمط RTL متوافقة مع شاشات الهواتف من 360px إلى 412px.
   - دعم ثنائي الاتجاه للمصطلحات الطبية الإنجليزية داخل النصوص العربية.
   - ثيم نهاري وليلي عالي التباين لسهولة القراءة في مختلف الظروف.

3. **مكتبة وسائط تعليمية منخفضة استهلاك الإنترنت**:
   - حماية الطلاب من التحميل التلقائي للملفات؛ عرض حجم ونوع الملف قبل الفتح.
   - ربط ملفات المحاضرات عبر روابط Google Drive وعروض PDF والصور الطبية بدقة محسنة.

4. **محرك موحد للاختبارات والمسابقات الطبية**:
   - حماية كاملة لمفاتيح الإجابات الصحيحة (`questionAnswerKeys`) في جهة السيرفر لمنع استخراجها عبر المتصفح.
   - حفظ تدريجي للإجابات سحابياً مع تنبيه لحالة الاتصال.
   - تصحيح خادمي موثوق ومحمي مع سياسات مرنة لإعلان النتائج.
